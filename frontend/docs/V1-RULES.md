# JenLow Network — V1 rules (approved direction)

## Publication permissions

| Publication | Actions |
| --- | --- |
| Bible verse | Internal share, Fire, daily prayer, inspiration for a Dream, **verse-only export** |
| Dream / Rêve | Internal share, private encouragement, public "Moi aussi" count, Fire, prayer |
| Dream / Initiation | Internal share, prayer, offer skills, suggest an introduction from My Circle |
| Dream / Croissance | Prayer only |
| Dream / Témoignage | Internal/external share, prayer, Fire, inspiration for a new Dream |
| Music | Internal share, Fire, submit audio adaptation/collaboration proposal |

No public like counter. Encouragement count is visible **only to the Dream owner**. The "Moi aussi" count is public, and **does not** grant co-ownership. Co-ownership is an explicit, accepted invitation; collaborators and fellow dreamers are different relationships.

### My Circle
People someone personally knows can be recommended to an Initiation Dream when skills match, but an introduction requires consent from both parties. Never disclose private contact details automatically. Matches are suggestions, not endorsements.

### Music
By publishing music in JenLow, the publisher accepts adaptation proposals by default. Only the original publisher may repost a proposed collaboration, and a repost must visibly credit every contributor. **Download songs is disabled in V1.** For external music, the sharer must identify the creator, source and the permissions/rights they have to share it. Uploading or reposting someone else's recordings still requires appropriate rights; in-app permission cannot override third-party copyright.

### Bible
Verse export is allowed; song export/download is not. Sharing a verse **into JenLow** from external Bible apps requires a future native share-target integration and depends on what the source app exposes.

### Lists
Fire is separate from Dreams. Prayer is one daily collection. A testimonial's "Inspired Dreams" total must count genuinely linked new Dreams in the backend, not saves or shares.

## MVP limitations
At present: demo local storage, example users and audio; no actual cross-user notifications, consent requests, counters, API or verified rights. These operations are interfaces/models to be wired to the future backend.
