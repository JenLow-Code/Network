# JenLow Network frontend assets

Store UI assets separately from code.

- \`audio/\`: three original short instrumental demonstrations (WAV, not copyrighted commercial recordings). Used by the three **Mes pierres** players in \`app/profile.tsx\`.
- \`images/\`: photos, thumbnails, illustrations and other approved imagery. Original Figma image exports should be put here; do not confuse illustrative demo icons with approved talent illustrations.
- \`icons/\`: exported vector artwork for talents and navigation if needed.

Existing Figma photos and illustrations were **not uploaded** with these changes; they must be exported from the original Figma for faithful reproduction.

All media in this repository is presently public, because the repository itself is public. Do not put private member files here.
